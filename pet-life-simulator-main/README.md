# ?? PetLife - Simulador de Pet Profissional

O **PetLife** é um simulador de estimação moderno, fofo e profissional desenvolvido com as tecnologias mais recentes do ecossistema React. Cuide da sua pet **Mel**, gerencie suas finanças e proporcione a ela a melhor vida possível!

## ?? Tecnologias

Este projeto utiliza uma stack de ponta para garantir performance e uma experiência de usuário fluida:

- **React 19**: A versão mais recente da biblioteca de UI mais popular do mundo.
- **TanStack Start / Router**: Gerenciamento de rotas e estado do servidor de última geração.
- **Vite 7**: O bundler mais rápido do mercado para um desenvolvimento ágil.
- **Tailwind CSS 4**: Estilização moderna, responsiva e baseada em utilitários.
- **Lucide React**: Ícones elegantes e consistentes.
- **Radix UI**: Componentes acessíveis e robustos.
- **TypeScript**: Segurança de tipos e melhor experiência de desenvolvimento.

## ? Funcionalidades

### ?? Cuide da Mel
- **Fome**: Mantenha-a alimentada com ossinhos e petiscos.
- **Felicidade**: Brinque com ela para manter o ânimo lá no alto.
- **Limpeza**: Não esqueça do banho e do dia de SPA.
- **Humor Dinâmico**: O estado da Mel muda de acordo com o nível de cuidado que ela recebe.

### ?? Economia e Loja
- **Ganhe Moedas**: Receba recompensas cada vez que você interage e cuida do seu pet.
- **Loja de Itens**: Use suas moedas para comprar itens que dão bônus significativos aos status da Mel.
- **Gestão de Inventário**: Escolha sabiamente quais itens comprar para manter o equilíbrio.

### ?? Resumo de Vida
- Acompanhe o progresso do seu pet em uma aba dedicada com estatísticas detalhadas e humor geral.

## ?? Como Executar o Projeto

Para rodar o PetLife localmente, siga os passos abaixo:

1. **Clonar o repositório:**
   `ash
   git clone https://github.com/seu-usuario/pet-life-simulator.git
   cd pet-life-simulator
   `

2. **Instalar as dependências:**
   `ash
   npm install
   `

3. **Iniciar o servidor de desenvolvimento:**
   `ash
   npm run dev
   `

4. **Acessar a aplicação:**
   Abra o seu navegador e acesse: http://localhost:8082 (ou a porta indicada no console).

## ?? Estrutura de Pastas

- src/assets: Imagens e recursos estáticos.
- src/components: Componentes React reutilizáveis.
- src/hooks: Hooks customizados.
- src/routes: Definição das páginas e rotas (TanStack Router).
- src/styles.css: Configurações globais de CSS e Tailwind.
